From 2022 to 2024 I have developed a library management system for the library in a local library. The software tries to automate as much as possible of the administration work, so adding new books means just scanning an ISBN.

* Draft and architect library system design
* Implement cloud solution with Restful API and Azure
* Automate routine tasks using Azure services
* Implement extensible system with plugins to auto-complete book information.
